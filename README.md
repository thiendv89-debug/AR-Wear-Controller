# AR Wear Controller

Source code for: Design and Development of a Wear OS-based Interactive Controller for Augmented Reality STEM Learning (AUT ENGE817, Dinh Van Thien, 24265051).

- Watch app (Kotlin, Wear OS): MainActivity.kt, HeartRate.kt, AndroidManifest.xml
- Phone bridge (Java): WearBridge.java
- Unity scripts (C#): WearReceiver.cs, CannonController.cs

Devices: Galaxy Watch 6 Classic, Galaxy S25, XREAL Air 2 Ultra (display via Samsung DeX).
